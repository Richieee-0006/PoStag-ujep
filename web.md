# PoStag-ujep

Dark Catppuccin Mocha UserCSS theme and layout overhaul for the UJEP IS/STAG university portal (`portal.ujep.cz`).

## Key Features
- **Catppuccin Mocha Theme:** Restyles inline styles, Bootstrap 5, Chosen.js, jQuery UI, and qTip into Catppuccin Mocha.
- **Flexbox & Grid Layout:** Replaces legacy table layouts with Flexbox/CSS Grid, a sticky sidebar, and a redesigned top bar.
- **Color-Coded Schedules & Enrollment:** Distinguishes lecture, lab, seminar, and exam blocks plus A/B/C pre-enrollment groups.
- **Responsive Tables:** Converts dense tables into card layouts on screens under `768px`.

## Tech Stack
- **Styling:** CSS3, UserCSS (`stylus.css`)
- **Extension:** Stylus (Firefox / Chromium)
